# 🧭 Dead Sea Explorers — مستكشفو البحر الميت

تطبيق تعليمي تفاعلي لطلاب **الصف السادس** في درس **A visit to the Dead Sea** من **English for Palestine 6B**.

## فكرة المشروع

يتعلّم الطالب الإنجليزية من خلال رحلة استكشاف: يتعرّف إلى المكان، يكتشف المفردات، يقرأ ويستمع، ويتدرّب على سؤال **Have you ever…?** ثم يراجع نتيجة التحدّي ويطبع شهادة تشجيعية.

## المحطات

1. **بداية المغامرة:** تقديم الرحلة وأهدافها.
2. **اكتشف المكان:** رسم تفاعلي للبحر الميت والواحة والصحراء.
3. **حقيبة الكلمات:** تسع بطاقات بالمعنى والنطق في جملة.
4. **صِل وتعلّم:** مطابقة أربع كلمات بمعانيها.
5. **اقرأ واكتشف:** نصّان قصيران مع أسئلة فهم وترجمة مساعدة.
6. **مختبر اللغة:** المضارع التام وأسئلة التجارب والإجابات القصيرة.
7. **ركّب السؤال:** ترتيب كلمات بالنقر أو بالسحب بالفأرة.
8. **اسمع واختر:** نشاطان مع نص بديل عند تعذّر الصوت.
9. **التحدّي والشهادة:** ستة أسئلة، مراجعة الإجابات والتفسير، وشهادة قابلة للطباعة.

## التغذية الراجعة والتقويم

- في **التدريب**: تفسير للإجابة الصحيحة؛ تلميح مناسب للخطأ وفرصة جديدة عند الإجابة الخاطئة.
- خمس مجموعات من التدريبات تمنح **خمس نجوم**؛ لا تتكرر النجمة عند إعادة النشاط.
- في **الاختبار**: تُثبّت إجابة واحدة لكل سؤال، ويظهر التصحيح بعد اكتمال الأسئلة الستة.
- إعادة الاختبار تستبدل نتيجته السابقة مع الإبقاء على نجوم التدريب.
- الشهادة تشجيعية وتعرض النتيجة الفعلية، وليست اعتمادًا رسميًا.

## التشغيل

نزّل المستودع عبر **Code → Download ZIP**، ثم فكّ الضغط وافتح **index.html** بمتصفح حديث مثل Chrome أو Edge.

لا يحتاج المشروع إلى تثبيت مكتبات أو إنشاء حساب للطالب. يمكن فتح ملف HTML مباشرة، أو استضافته على أي خدمة تستضيف ملفات ثابتة.

### GitHub Pages (اختياري)

من إعدادات المستودع: **Settings → Pages → Deploy from a branch → main → /(root) → Save**. بعد انتهاء النشر سيظهر رابط الموقع في صفحة Pages. وجود الكود في المستودع وحده لا يعني تفعيل Pages.

## ملاحظات الاستخدام

- الواجهة عربية، والنصوص والأمثلة التعليمية بالإنجليزية.
- يعمل على الهاتف والحاسوب؛ النقر بديل للسحب، ولوحة المفاتيح مدعومة.
- يوجد زر لتكبير الخط، واحترام لإعداد تقليل الحركة.
- يُحفظ التقدم في **localStorage** في المتصفح فقط. عند مشاركة الجهاز، استخدم **بدء رحلة جديدة**.
- لا تُرسل أسماء الطلاب أو إجاباتهم إلى خادم، ولا يُحفظ اسم الشهادة.
- الصوت يستخدم **Web Speech API** وصوتًا إنجليزيًا متاحًا على الجهاز. قد يحتاج اتصالًا أو تنزيل حزمة صوت؛ توجد نصوص بديلة.
- لحفظ الشهادة PDF: افتح الشهادة ثم اضغط **طباعة / حفظ PDF** واختر **Save as PDF** من نافذة المتصفح.
- زر **نسخة HTML** يحفظ نسخة مستقلة من التطبيق. التقدم مرتبط بمتصفح الطالب وليس ملفًا مشتركًا.

## دليل المعلّم

زر **دليل المعلّم** داخل التطبيق يشرح الأهداف وتسلسل التدريس والتقويم. يُقترح أن يسأل الطلاب بعضهم بعضًا عن تجاربهم الحقيقية بعد نشاط تركيب السؤال.

## المصادر

- الرزمة التعليمية المرفقة للصف السادس، **English for Palestine 6B**، الوحدة الأولى **A visit to the Dead Sea**، الصفحات المطبوعة **2–4**: مصدر موضوع الدرس والمفردات والقاعدة.
- الملف المرفق **English Interactive Learning Feedback, Activities & Quizzes**: مرجع لفكرة التغذية الراجعة الإيجابية والتلميح والمحاولة الجديدة.
- مثال رحلة الفراشة المرفق: مرجع لفكرة التعلّم عبر محطات تفاعلية.
- الرسوم التوضيحية والأنشطة والواجهة مطوّرة لهذا المشروع. رسم المكان تخطيطي وليس خريطة جغرافية دقيقة.

## التقنية والتحقق

ملف HTML واحد يضم CSS وJavaScript وSVG، دون مكتبات خارجية وقت التشغيل.

أُجري فحص صياغة JavaScript واختبار آلي لمسار الطالب باستخدام jsdom، شمل التغذية الراجعة والمحاولة الجديدة، احتساب النجوم والنتائج، استئناف الاختبار، الشهادة وحماية إدخال الاسم، وإعادة التعيين. لم يتوفر اختبار بصري بمتصفح كامل في بيئة الإنشاء؛ تشغيل الصوت والطباعة يحتاج تجربة على الجهاز المستخدم.
